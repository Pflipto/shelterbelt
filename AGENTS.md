# Shelterbelt

This is Thomas Pflipsen’s portfolio workshop. Keep the site simple, accessible, and useful. Preserve the Digital Agrarian / Modern Editorial identity: warm paper, deep green, wheat accents, Newsreader headlines, and Inter interface text.

- Use the existing checkout; do not create worktrees unless requested.
- Keep changes small and explain substantial changes before implementation.
- Prefer plain HTML/CSS. Avoid runtime dependencies without a concrete need.
- Validate desktop/mobile layout, keyboard navigation, links, and font loading.
- Be explicit about checks that failed or were not run.
- Work on branches and submit focused PRs. Do not push directly to main.
- Do not merge, deploy to production, change DNS, or create infrastructure without explicit approval.
- Never commit credentials.
